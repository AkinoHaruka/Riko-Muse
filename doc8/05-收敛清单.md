# 05｜收敛清单：以 Muse 可观察集为上限（留 / 砍 / 冻结）

主人硬规矩（2026-10-23 23:13 提出、23:19 澄清）：「不准过度开发。」判定按总原则三档（2026-10-09 定）：

- **Muse 确定有的 → 一定要有**（留，全量）。
- **Muse 高度可推断有的 → 也要有**（留·简化：能力在，做法取最简，不许把推断当借口造重型机器）。
- **Muse 确定没有的 → 一定不要有**（砍）。
- 三档之外的 → 按旧规矩「Muse 为准、双生填空」处理；已建成的归冻结。

本清单第一版曾把「不可观察」一刀切成砍/冻结，23:19 经主人纠正后按三档重排：不可观察不等于没有，强推断成立的能力要留（简化实现），只有纯自创机器才砍。

## 留（文件形态承接，做法向 Muse 看齐）

| 项 | Muse 形态 | 文件做法 |
|---|---|---|
| 按日笔记与事件轨迹 | 按日 Markdown | daily note 逐字块（F1 语法已备） |
| 记忆条目（事实/偏好/指令/经历）与状态（新代旧、忘） | curated 总览 + claim 先后关系 + forget 清理 | MEMORY.md 总览 + 条目文件，只存状态与取代关系，不存版本锁 |
| 来源引用与 explain | 每条记忆可回指来源 | 条目引用 evidence 块 ID；span 只作定位，不做逐字复核机器 |
| 词法搜索 | 稀疏检索 | 可重建 FTS 索引（投影，非事实源） |
| 向量与混合召回 | embedding 索引 | 可重建向量分片（投影） |
| Soul | 每 agent 一份 SOUL.md 可编辑 | agents/<id>/SOUL.md（F1 语法已备） |
| compact 与四分面 bank | MEMORY 总览 + bank 四文件 | 同名同构落盘，算法沿用 facet_v1 |
| 人物/组页面与索引 | people/groups 页 + INDEX | 同名同构落盘 |
| alignment 合成 | 后台派生 synthesis | memory/alignment.md 派生文件 |
| 后台整理工序 | 定时整理/合并 | 简单定时任务读写文件，无作业租约机器 |
| 承诺/目标跟踪 | 目标与跟踪项 | commitments 文件 |
| 导出与自检 | 文件可导出 | export 只读渲染 + doctor 基础校验 |

## 留·简化（高度可推断有：能力保留，做法取最简）

| 项 | 推断依据 | 简化做法 |
|---|---|---|
| 写完整性（不出现半状态） | Muse 多会话与后台写从不损坏文件，必有基本保护 | 单文件临时写+rename 替换 + 简单文件锁；不要 generation/manifest/指针协议 |
| 版本与取代链 | explain 可见 claim 版本与 replaced-by 关系 | 条目存 version 与 supersedes 字段即可；不要 CAS 协议 |
| 幂等去重 | 重复保存不产生重复记忆 | 内容指纹去重；不要正式回执文件体系 |
| 忘后不复活 | forget 后旧内容不再被召回 | forget 时写一条抑制记录（ID+hash）；不要 tombstone 栅栏体系 |
| 用户隔离 | Muse 产品层必然隔离不同用户 | 每用户一目录 + token 摘要映射；不要多租户权限机器 |
| 会话摘录检索 | memory_search 能返回往日对话摘录 | entries 作为检索来源并入普通搜索；不单独成道、不单独生命周期 |
| 后台工序记账 | 定时工序存在且不重复执行 | 一份简单的已处理账本；不要 lease/heartbeat 状态机 |
| 常驻 | MEMORY.md 恒在上下文 | curated 总览即常驻；不要 pin 协议 |

## 砍（确定没有 / 纯自创机器，不搬、不建）

| 项 | 理由 |
|---|---|
| generation 原子事务引擎（F2，已停工） | staging/manifest/指针协议是自创重型机器，完整性已由「留·简化」承接 |
| mutation receipt 正式回执体系 | 自创；幂等已由指纹去重承接 |
| 作业 lease/heartbeat/claim 状态机 | 自创；记账已由简单账本承接 |
| purge tombstone fences 栅栏体系 | 自创；抑制记录已承接「忘后不复活」 |
| Resident pin 协议 | 自创协议层；总览即常驻 |
| repair 授权工作流（propose/授权/关闭状态机） | repair 线程可作普通派生笔记，授权机器自创 |
| memory domains 与跨域 grants | 无对应物、无强推断 |

## 冻结（现网 SQLite 原样，不移植不扩展）

- schema 24 SQLite 内核整体：现网继续运行，功能冻结在当前版本。
- 后台闭环 ledger、generation artifacts、域绑定、审计分层、revision 历史：均随内核冻结。
- F8 转换器、F9 部署切换：随范围收敛一并冻结——文件形态先在本机以 Muse 功能集跑通，再谈部署。

## 收敛后的 F 线（重排草案）

- F1 格式基座：已完成，保留（语法本身不含过度机器）。
- F2′ 文件存储直读直写：无事务引擎，按 Muse 方式直接写文件 + 简单文件锁防并发写坏；索引重建其后。
- F3′ 读路径：搜索/explain/bundle 只读规范文件 + 投影索引。
- F4′ 后台工序与 forget 闭包：定时整理、派生刷新、forget 清源/派生/索引。
- 每卡开工前仍需主人点头；本清单确认后按此重写 doc8/04。
