状态：**v1 实现规范，尚未实现**。更新日期：2026-09-24。后续开发先读 [10-开发冻结规范](10-开发冻结规范.md)。

本目录是新 Rust 优先 Agent Memory 项目的开发依据。三个开源仓库位于上级目录；本目录没有复制它们的代码。文中用「上游事实」标记已在指定源码或文档中看到的行为，用「本项目决策」标记我们为新项目选定的行为，用「待实现」标记尚未交付的能力。实现与文档不一致时，应先记录差异并修改文档或代码，不能悄悄改变契约。

## 已由用户确定

1. 产品是供不同 Agent 使用的通用记忆内核，Rust 优先。
2. 第一版接入 DeepSeek Harness（DSH）。
3. 同一用户的不同 Agent 默认可读同一长期记忆；不同用户相互隔离。
4. 第一版从空库开始，不迁移 Riko／Companion 旧数据。
5. 可信度机制参考三个项目的实际做法，避免凭空发明复杂规则。
6. 不设耗时的 API 验证或基准测试阶段。开发过程中只做保证功能可运行的必要验证。

## 设计摘要

```text
DSH 会话事件 ──→ DSH 适配器 ──→ Rust 内核 ──→ 证据日志
                                     │              │
                                     │              └→ 候选提取 → 可用记忆
                                     ├→ 同用户范围检索 → 有界上下文 → DSH Agent
                                     └→ 纠错／遗忘 → 原子更新 → 索引同步
```

记忆可由同一用户的多个 Agent 使用。每条记录保留来源 Agent 与原始会话引用，读权限由用户身份决定。模型提取结果必须保留证据，不能仅凭生成文字获得更高权限。
