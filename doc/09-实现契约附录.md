# 09 运行、诊断与恢复约定

本文件定义 v1 的操作面。建表以 [11-数据库v1迁移](11-数据库v1迁移.md) 为准，协议以 [12-HTTP协议v1](12-HTTP协议v1.md) 为准，状态算法以 [13-算法与模型契约](13-算法与模型契约.md) 为准。本文件没有第二套 SQL 或接口草案。

## 启动配置

`memoryd` 读取独立配置文件和秘密文件路径。非秘密配置包括监听地址（默认 `127.0.0.1:8791`）、SQLite 路径、spool／任务上限、模型 endpoint 与 model name、提取 timeout、上下文上限。模型密钥与每用户令牌不得写在仓库配置或命令行参数中。进程启动顺序：验证 loopback 绑定 → 读取配置 → 打开数据库与 WAL → 校验并执行迁移 → 检查用户表与索引状态 → 启动 worker → 开放 HTTP。

启动日志只输出配置项名称和值中的非秘密字段。数据库打不开、迁移校验不符、令牌表损坏、bind 到非 loopback、模型配置与启用提取状态矛盾时启动失败，并返回明确错误码。模型端点暂时不可达可启动服务，但提取作业进入可见失败状态；手工记忆和搜索仍可工作。

## CLI 命令

| 命令 | 作用 | 约束 |
|---|---|---|
| `memoryd serve --config <file>` | 启动内核 | 只监听 loopback |
| `memoryd principal add --tenant <id> --user <id> --token-out <file>` | 创建用户令牌 | 文件不能已存在；数据库仅存 hash |
| `memoryd principal rotate-token --tenant <id> --user <id> --token-out <file>` | 换令牌 | 原令牌立即失效 |
| `memoryd doctor --config <file>` | 只读诊断迁移、外键、索引、任务 lease | 不修复数据 |
| `memoryd rebuild-index --config <file>` | 从 active 规范表重建 FTS/grams | 不复活 forgotten |
| `memoryd jobs list --status dead` | 看失败任务 | 不打印对话正文 |
| `memoryd jobs retry <id>` | 将 dead job 重新排队 | 保持相同 window_key，有限重试需显式管理授权 |
| `memoryd backup <path>` | SQLite 在线一致性备份 | 不只复制 WAL 模式下的主 db 文件 |

`restore` 属于停机维护操作，v1 交付文档应写明“停止服务 → 备份现库 → 校验恢复文件 schema 和用户列表 → 替换 → doctor → 启动”。未实际实现 CLI 命令前，不得在 README 中假装可用。

## 可观测性

每次 evidence ingest、flush、worker、search、compose、correct、forget 记录 request ID、不可逆的 scope 短哈希、结果码、耗时。日志不输出原始对话、quote、令牌或模型密钥。worker 额外记录 job ID、attempt、model name、input/output tokens（提供者返回时）、错误类别。指标至少包括 queued/dead job 数、模型失败次数、索引 dirty 状态、检索耗时和 compose 截断次数。

健康接口只报告数据库和索引状态，不暴露用户列表。用户可由自己令牌查看本 scope 的任务状态。错误码按 [12](12-HTTP协议v1.md) 约定，不在 DSH 适配器里猜测“空结果就是成功”。

## 故障恢复优先级

1. **规范库损坏**：停止服务，保留原文件，使用最近一致性备份恢复。不能拿派生索引覆盖规范库。
2. **索引损坏／dirty**：规范库仍可读；有界降级查询，运行 `rebuild-index`。普通召回始终按 active 状态过滤。
3. **模型失败**：L0 不受影响；任务重试 3 次后 dead，由管理员查看 job ID；不反复无限调用付费 API。
4. **DSH 适配器网络失败**：本机 spool 保留未 ack 事件，重启按原唯一键重放。
5. **用户纠错或遗忘后缓存陈旧**：以规范库状态为准，立即排除旧记录；索引和上下文缓存不得绕开该过滤。

## 输出状态用语

实现报告分别写：文档完成、代码已修改、已编译、最小检查通过、DSH 实际运行、已安装、已部署。没有运行过的状态写“未验证”。首版不声称已达到三个上游项目的性能或基准分数。
