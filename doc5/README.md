## 目标

把 L0 用户证据 → 模型候选 → Rust 准入 → active 记忆 → 有界召回之间的判定写成可编码、可审计、可用反例检验的规则。同一用户跨 Agent 默认共享、不同用户隔离、逐字证据、纠错与遗忘语义继续有效。

本轮不调用外部模型。施工可用固定候选、临时 SQLite、离线查询和本机固定响应。未来是否恢复少量真实模型观察由用户另行决定；确定性检查通过只证明规则执行正确。
