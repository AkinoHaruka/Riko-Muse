## 0. 定位

身份隔离与记忆选择是两件事：认证 `ScopeKey`（tenant/user）保持不变；新增独立
`MemoryDomain` 与 `DomainScope`（写域 + 读域集）。domain_id 是存储边界，session_id 是
来源标识；多次会话可绑定同一域。同用户默认共享 user_main；side 域默认继承 user_main
读取（本项目策略，非 Muse 已证实矩阵）；主域不自动读 side。

## 1. 迁移 0015（DDL 冻结）

新增迁移 `0015_memory_domains.sql`；`0001`—`0014` 冻结不动；`SCHEMA_VERSION 14 → 15`。

### 1.1 新表

```sql
-- 域注册表：user_main 隐式存在；旧数据经 principals 回填一行 user_main。
CREATE TABLE memory_domains (
  tenant_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  domain_id TEXT NOT NULL,
  kind TEXT NOT NULL CHECK (kind IN ('user_main','side')),
  status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','closed')),
  policy_version INTEGER NOT NULL DEFAULT 1,
  created_reason TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  PRIMARY KEY (tenant_id, user_id, domain_id),
  FOREIGN KEY (tenant_id, user_id) REFERENCES principals(tenant_id, user_id)
);

-- 会话→域绑定：可信宿主/用户经 API 登记；普通 Agent 不可改；同会话唯一。
CREATE TABLE session_domain_bindings (
  tenant_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  host_id TEXT NOT NULL,
  session_id TEXT NOT NULL,
  domain_id TEXT NOT NULL,
  registered_by TEXT NOT NULL DEFAULT 'trusted_user',
  created_at TEXT NOT NULL,
  PRIMARY KEY (tenant_id, user_id, host_id, session_id),
  FOREIGN KEY (tenant_id, user_id, domain_id)
    REFERENCES memory_domains(tenant_id, user_id, domain_id)
);

-- 跨域授权：reader 域额外可读 granted 域；可信用户/管理员配置；撤销置 revoked_at。
CREATE TABLE cross_domain_grants (
  id TEXT PRIMARY KEY,
  tenant_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  reader_domain TEXT NOT NULL,
  granted_domain TEXT NOT NULL,
  granted_by TEXT NOT NULL,
  reason TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  revoked_at TEXT,
  FOREIGN KEY (tenant_id, user_id) REFERENCES principals(tenant_id, user_id)
);

-- L0 证据域映射：evidence_events 保持来源身份；域归属记在本表。
-- 域功能未启用时不写行；无映射行的事件按 user_main 处理。
CREATE TABLE evidence_domain_map (
  tenant_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  evidence_id TEXT NOT NULL,
  domain_id TEXT NOT NULL,
  created_at TEXT NOT NULL,
  PRIMARY KEY (tenant_id, user_id, evidence_id),
  FOREIGN KEY (tenant_id, user_id, domain_id)
    REFERENCES memory_domains(tenant_id, user_id, domain_id)
);
```

### 1.2 既有表 ADD COLUMN `domain_id TEXT NOT NULL DEFAULT 'user_main'`

一等对象直接加列；缓存/子表（grams/FTS/向量/证据行/revision/relations/pins 等）不加列，
经 join 父对象继承域。名单：

`memories`、`memory_candidates`、`extraction_jobs`、`memory_pages`、`consolidation_jobs`、
`semantic_jobs`、`repair_threads`、`dream_jobs`、`suppressed_sources`。

### 1.3 约束重建（SQLite 不能原地改 PK/唯一索引）

- `alignment_synthesis`：重建为 `PRIMARY KEY (tenant_id, user_id, domain_id, version)`，
  旧行复制为 `user_main`。派生链按域独立版本。
- `purge_tombstones`：重建为 `PRIMARY KEY (tenant_id, user_id, domain_id, source_kind, source_id)`，
  旧行复制为 `user_main`。墓碑按域防重放。
- `pages_published_unique` 唯一索引：重建为
  `(tenant_id, user_id, domain_id, document_kind, document_key) WHERE status='published'`。
- **不重建**：`dream_jobs` 的 `UNIQUE (tenant,user,trigger_key)` 跨域 trigger_key 冲突
  留到 V2-B1（per-domain dream 调度尚未实现）迁移处理，本期如实记录；`rupture_scan_cursors`
  保持全局游标（单遍扫描，rupture_events 行按事件映射域打标）。
- `rupture_events` ADD COLUMN `domain_id`（取事件映射域；无映射按 user_main）。

### 1.4 回填

`memory_domains` 从 `principals` 回填每个 (tenant,user) 一行 `user_main`（kind='user_main'，
created_reason='migration_backfill'）。其余列默认即回填。旧数据保留原 tenant/user、ID、
版本、证据与内容，全部归属 user_main。

## 2. 域解析（服务端 Rust 裁决）

### 2.1 配置

```toml
[domains]
# V2-S1 总开关。false（缺省）：所有请求解析为 user_main 缺省域，行为与 14 版本一致；
# 不写 evidence_domain_map；管理端点全部 403。
enabled = false
```

### 2.2 写域（有 origin 的请求：ingest、remember、correct、forget、retire、restore、flush）

`write = session_domain_bindings[(tenant,user,host,session)] ?? 'user_main'`。
服务端不信任请求体中的任何域字段；Agent 任意写 domain_id 不能提升权限。
一致性闸：remember 时校验证据事件的映射域（无映射按 user_main）等于写域，不等拒绝
（`StateConflict`，对应「同事件绑定冲突明确拒绝」「已存在 evidence 的重放不得更改域」）。

### 2.3 读域集（读端点：get/search/compose/bundle/explain、页面、resident、alignment）

- enabled=false：恒为 `{user_main}`。
- enabled=true：请求头 `X-Riko-Memory-Domain` 指定读域（缺省 user_main）。
  服务端校验该域存在且 active；读域集 = `{D}` ∪（D 为 side 时 `{user_main}`）∪
  `{G | cross_domain_grants(reader=D, granted=G, revoked_at IS NULL)}`。
  非法/未知道 → 404 `domain_not_found`；closed 域 → 409。
- 无请求头选择器的旧客户端只能落在 user_main，不能越界。

### 2.4 后台作业

extraction/consolidation/semantic/dream/alignment 刷新按作业行的 domain_id 构造
`DomainScope { write: job.domain, read: job.domain ∪ (side 时 user_main) }`。
后台结果可见域不得比来源更广；多域派生本期不产生（每作业单域）。

## 3. 存储层契约

- `memory-domain` 新增纯类型：`USER_MAIN_DOMAIN`、`DomainScope { write, read }`
  （`user_main()` 构造、`new` 保证 write ∈ read、`read_json()` 供 SQL 绑定）。
- 读路径统一追加 `AND domain_id IN (SELECT value FROM json_each(?N))`（单对象 get 同样；
  缓存表经 join 父对象过滤）。
- 写路径 INSERT 带写域；**去重按写域过滤**（同文记忆在 main/side 保留各自身份，不跨域
  dedup、不跨域更新旧版本）；correct/forget/retire/restore 仅作用于写域内对象。
- suppressed_sources / purge_tombstones 匹配按写域；purge 作用域=指定域，不跨域删除。
- flush 建作业带写域；窗口内事件映射域混合时拒绝（`StateConflict`）。
- 域功能关闭（enabled=false）时恒传 `DomainScope::user_main()`，全部查询结果与 14 版本
  一致；响应 JSON 键集不新增（跨域来源标记随 V2-H1 bundle 分段交付）。

## 4. HTTP API（enabled=false 时全部 403 `domain_disabled`）

| 方法/路径 | 语义 |
|---|---|
| `GET /v1/domains` | 列出本 scope 域（含状态、kind、policy_version） |
| `POST /v1/domains` | 建 side 域 `{domain_id, reason?}`；user_main 保留名拒绝；幂等回 200 |
| `POST /v1/domains/close` | 关闭域 `{domain_id}`（数据保留、不可再作为读/写/绑定目标） |
| `GET /v1/domains/bindings` | 列出会话绑定 |
| `POST /v1/domains/bindings` | 登记绑定 `{host_id, session_id, domain_id}`；已存在且目标不同 → 409 |
| `DELETE /v1/domains/bindings/{host_id}/{session_id}` | 解除绑定 |
| `GET /v1/domains/grants` · `POST /v1/domains/grants` · `DELETE /v1/domains/grants/{id}` | 跨域授权管理（建/列/撤） |

以上均为本 scope 自助配置（可信用户/管理员），逐项写 audit_events
（action=`domain_admin`，detail_json 含操作、目标、操作者 actor）。

## 5. 验收（对应 V2 文档 02 §6）

离线 store 测试（`v2_domain_tests`）必须覆盖：

1. 旧库升级：已有数据 domain 全为 user_main；memory_domains 回填；旧行为测试全绿。
2. main/A/B 矩阵：主读不到 A；A 读到 A+main、读不到 B；授权跨读后 B 读到 A。
3. 同 quote main/A 各自 ID/版本；dedup 互不污染；A 的 correct/forget 不动 main。
4. 非法域头 404；closed 域 409；绑定冲突 409；证据重放改域被拒。
5. purge/suppressed 墓碑按域；main 墓碑不拦 side 重放。
6. alignment 按域独立版本链；页面同 key 跨域可各自发布。
7. 写域恒 ∈ 读域集；read_json 绑定正确。

档位：`cargo build --workspace && cargo test --workspace`（构建/测试通过）→ 临时库
HTTP 冒烟（域管理端点 + 域头读 + 绑定写路径；本机 CLI+HTTP 冒烟）。真实 DSH 闭环、
真实模型连通、dana/realtest：**本卡不涉及，未验证**。
