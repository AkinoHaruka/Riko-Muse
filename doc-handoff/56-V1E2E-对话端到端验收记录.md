## 1. 验收目标与纪律

### 目标
验证在主人服务器上运行的生产单容器服务 `riko-muse-app-1` 能够走通全链路真实模型交互：
`DSH 会话创建` → `插件检索并注入记忆` → `OpenRouter nemotron 模型回复` → `回复中准确运用记忆`。

### 纪律执行
- **只读验收**：未修改任何代码、未修改任何部署配置、未重启容器、未变动生产数据库历史数据（仅创建本次验收会话及其对话记录）。
- **凭据保护**：Web 认证 Token 及各类 API Key 均未打印、未持久化、未记录于报告中。
