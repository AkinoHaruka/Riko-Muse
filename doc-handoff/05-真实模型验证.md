## 2. 链路 2：DSH 真实模型新会话自然召回并正确使用 ✅ 真实模型连通（经本地协议转换装置）

新 headless 会话（与链路 1 无共享会话），中性问句 **「以后你回答我的问题时会注意什么？」**：

```
proxy-requests.log 主请求: n_tools=29  saw_injection=true   ← 内核 compose 注入 <agent_memory …> 块
回答：全程中文，按「结论/理由」结构逐条列出执行规则，结尾

     ← 注入记忆（用中文、简洁、先结论后理由）被模型实际采用
```

事件线同时验证：carol 会话的 user/assistant 事件捕获入库、spool receipt 齐 ack。

### 顺带确认的边界（非缺陷，如实记录）

- **召回是词法的**（FTS 拉丁 + 中文二元字 + RRF）：
  「怎么做蛋炒饭？」与该记忆零词法重叠 → compose 返回空、不注入（`saw_injection=false`）——这是检索
  语义的正确行为；换含「以后回答」的自然问句即召回（grams，score 1.0）。语义化召回是后续课题。
- 新库 `doctor` 报 `index_dirty=1`（写入后待重建），grams 兜底仍工作（`index_degraded:true` 不影响命中）。
- 真实模型会自作主张填枚举（如把 kind 填成「指令」）——靠内核闸门拒绝/重试兜底，符合「模型只是候选」设计。
