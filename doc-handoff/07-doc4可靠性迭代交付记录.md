## 2. 关键行为契约（与 doc4/02—04 一一对应）

- **状态机**：`queued/running/retryable_failed/succeeded/dead`。到期条件对 `queued/retryable_failed` 统一为 `run_after<=now`（5/15/45s 退避不可绕过）；`lease_until` 只管 `running` 所有权。每次领取/恢复原子递增 `claim_generation`；旧代际的续租、候选写入、成功/失败提交一律失效（`STALE_CLAIM`）。
- **过期 running 恢复**：每轮领取事务内先恢复 `lease_until<=now`（或 NULL）的 running：generation+1、attempts+1、`WORKER_LEASE_EXPIRED`，未满 3 次按本次延迟回 retryable，满 3 次 dead。
- **跨会话公平**：前窗阻断按 `(tenant,user,host,session)` + `through_event_seq` 数值判定；一个 session 的 dead/running 前窗只阻断本 session，其他 session 照常领取。
- **服务端分窗**：flush 在单事务内读取 `(已排最大 through, 请求 through]`，按与 worker 共用的实际 JSON 序列化字节贪心切窗（≤100 事件且 ≤32 KiB）；单事件超限 → 单独 `dead/WINDOW_TOO_LARGE`（attempts=0，不调用模型，L0 保留）；空洞与无 user/user 组 → `succeeded` 零模型调用 checkpoint。
- **人工跳过**：`memoryd job skip` 仅接受 `dead + WINDOW_TOO_LARGE`，写 `extraction_job_skips` + 审计（`admin_cli/local_admin`），重复幂等；skip 只跳过该窗口自动提取，不删 L0。
- **诊断**：`GET /v1/jobs`（默认 dead，keyset cursor，SQL 全分支显式 scope）；详情含 `skipped/prompt_version/model_name/tokens`；`candidates list/show` 只读（不提供 promote）；doctor 聚合各状态作业数、lease 过期 running、未跳过/已跳过 dead、held 数、最老待办时长。

## 3. 可复制运行说明（空库 → 固定响应作业 + 失败恢复 + 超限诊断）

以下命令在 2026-09-25 于本机（Windows，Git Bash）真实执行并复核，输出摘要见各步注释。工作目录 `C:\TRAE\Agent-Memory`；需要先 `cargo build --workspace`。

```bash
# 0) 准备临时库与令牌（不碰真实用户库）
DEMO=$(mktemp -d)
./agent-memory/target/debug/memoryd principal add --tenant demo --user carol \
  --token-out "$DEMO/carol.token" --db "$DEMO/demo.db" --migrations agent-memory/migrations

# 1) 配置：模型端点指向本机固定响应 mock（3979），先不启动 mock
printf 'listen_addr = "127.0.0.1:8798"\ndb_path = "%s"\nmigrations_dir = "agent-memory/migrations"\nmodel_endpoint = "http://127.0.0.1:3979/v1/chat/completions"\nmodel_name = "mock-extract"\nmodel_key_file = "%s/model.key"\nmodel_allow_empty_key = true\n' \
  "$(cygpath -m "$DEMO/demo.db")" "$(cygpath -m "$DEMO")" > "$DEMO/config.toml"
touch "$DEMO/model.key"
./agent-memory/target/debug/memoryd serve --config "$DEMO/config.toml" &
T=$(cat "$DEMO/carol.token" | tr -d '\r\n')

# 2) 写入 + flush；模型端点关闭 → 作业失败落 retryable（MODEL_UNAVAILABLE，退避 5/15s）
printf '{"origin":{"host_id":"dsh","agent_id":"agent-a","session_id":"s1"},"event_seq":1,"role":"user","source_kind":"user","occurred_at":"2026-09-25T09:00:00Z","content":"hello demo one"}' > "$DEMO/ev1.json"
printf '{"host_id":"dsh","session_id":"s1","through_event_seq":1}' > "$DEMO/flush.json"
curl -s -X POST -H "Authorization: Bearer $T" -H "Content-Type: application/json" \
  --data-binary @"$DEMO/ev1.json" http://127.0.0.1:8798/v1/evidence/events
curl -s -X POST -H "Authorization: Bearer $T" -H "Content-Type: application/json" \
  --data-binary @"$DEMO/flush.json" http://127.0.0.1:8798/v1/extraction/flush
sleep 3
curl -s -H "Authorization: Bearer $T" "http://127.0.0.1:8798/v1/jobs?status=retryable_failed"
# → {"attempts":1,"error_code":"MODEL_UNAVAILABLE","status":"retryable_failed",...}

# 3) 三次失败后 dead（JOB_MAX_ATTEMPTS=3，attempts 累计不清零）；
#    启动固定响应 mock 后管理员 retry → succeeded（本次演示 attempts=4、记录 usage 42/3）
python doc-handoff/mock_extract_server.py &      # 固定响应，不调用任何真实模型
curl -s -X POST -H "Authorization: Bearer $T" "http://127.0.0.1:8798/v1/jobs/<JOB_ID>/retry"
curl -s -H "Authorization: Bearer $T" "http://127.0.0.1:8798/v1/jobs/<JOB_ID>"
# → {"status":"succeeded","attempts":4,"model_name":"mock-extract","input_tokens":42,...}

# 4) 超限诊断：写入单条 40 KB 事件并 flush → 服务端分窗创建 dead/WINDOW_TOO_LARGE
#    （attempts=0）+ 正常 queued 后窗；响应 job_id 是最后一个作业
python -c "…写 ev2.json(seq2, content 40000 字节) 与 ev3.json(seq3)…"   # 见演示脚本
printf '{"host_id":"dsh","session_id":"s1","through_event_seq":3}' > "$DEMO/flush2.json"
curl -s -X POST -H "Authorization: Bearer $T" -H "Content-Type: application/json" \
  --data-binary @"$DEMO/flush2.json" http://127.0.0.1:8798/v1/extraction/flush
# → {"job_id":"<through3 的 queued 作业>","status":"queued"}
curl -s -H "Authorization: Bearer $T" "http://127.0.0.1:8798/v1/jobs?status=dead"
# → [{"through_event_seq":2,"status":"dead","error_code":"WINDOW_TOO_LARGE","attempts":0,"skipped":false}]

# 5) retry 被拒（409，提示 skip）；skip 后列表出现 skipped=true；L0 原文仍在库
curl -s -X POST -H "Authorization: Bearer $T" "http://127.0.0.1:8798/v1/jobs/<DEAD_ID>/retry"
# → 409 {"message":"WINDOW_TOO_LARGE 不允许原样 retry；请用 memoryd job skip 显式跳过，或先修复输入"}
./agent-memory/target/debug/memoryd job skip --config "$DEMO/config.toml" --tenant demo --user carol \
  --job-id <DEAD_ID> --reason "demo: single event over 32KiB window"   # 重复执行幂等
./agent-memory/target/debug/memoryd doctor --config "$DEMO/config.toml"
# → jobs queued=… dead=…（未跳过=… 已跳过=1）… oldest_pending=…（只聚合，不打印用户列表）
```
