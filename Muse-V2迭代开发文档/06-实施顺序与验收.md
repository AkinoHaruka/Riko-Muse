## 2. 迁移与接口纪律

迁移 0001—0014 全部冻结。0015 起按实际提交顺序编号，不先把 0015/16/17 绑定到尚未定型的表；每卡更新 SCHEMA_VERSION、version/CLI/doctor 及 checksum 记录。

当前迁移器自动应用前向迁移，没有通用 down 契约。原稿“每迁移必须 up+down”改为：只在副本演练前向迁移和完整性检查，回退通过可验证备份/旧版本恢复流程。禁止自动 DROP 新表伪装安全降级；升级与生产部署须独立授权，不能用新 Store 的 backup/doctor 打开原库。

本阶段新选择器、读接口、后台输出以新增 V2 profile/版本实现。现有公共路径保持已冻结行为；旧客户端兼容与新域默认授权单独覆盖。无需模型重写现有历史证据，默认旧数据主域归属明确。

## 3. 行为验收矩阵

先写合成对话和人工预期，再运行；不围绕 cue 或具体实现量身设计。每案例固定 source refs、授权范围、应保存/应 held/应沉默、应注入、应读取、最终答案。

| 编号 | 场景 | 必须观察到的结果 |
|---|---|---|
| V01 | 普通新会话回忆用户长期偏好 | compact 或 recall 可找到有效事实；不会把 routine log 常驻 |
| V02 | 用户表达重要变化后即时保存 | 成功回执后才声明保存；后台之后整理一致且不重复 |
| V03 | 写失败/索引延迟 | 不宣称成功；已成功规范写入可直接 get，空 search 不否认保存 |
| V04 | 同名/昵称/“我丈夫”/代词 | 可解时读正确实体详情；歧义不猜、别名不误归并 |
| V05 | 索引预算外的相关人物 | resolve/search 找到并先读；不能因 top-5 截断遗漏 |
| V06 | scheduled handoff / 群组活动推荐 | 用匹配的人物/群组详情与当前动态，引用相关且无突兀细节 |
| V07 | main、side A、side B | 默认矩阵与授权跨读正确；猜 ID、语义、索引、explain 均不串域 |
| V08 | 主域和侧聊保存相同 quote | 各自 ID/版本/来源，dedup、更正、遗忘不互相污染 |
| V09 | 四分面与 compact | 跨 kind 合理归面、条件/主体/日期保留、空分面允许、重复去除 |
| V10 | 用户问“从哪知道、旧值是什么” | explain 返回逐字依据、speaker 和前后链；动机未知则明说未知 |
| V11 | 更新/expired/retired/forget | get、bundle、实体/分面/entry/向量/导出即时失效，不等待小时任务 |
| V12 | purge 单条来源及混合页 | 影响预览正确；只清受影响内容，旧缓存/审计正文/作业副本不能复活 |
| V13 | 用户自我纠正与责备过去错误 | 自我纠正不误报 Agent rupture；无 cue 的真实抱怨进入复核 |
| V14 | 多话题纠正与再次复发 | 话题不错误归并；repair 指向具体行为，有证据的复发/关闭 |
| V15 | quiet 与 hourly/nightly 重叠 | 同一信号只消化一次；无新信号零调用；定时调用有次数/token 上限 |
| V16 | worker 崩溃、重试、来源途中更正 | 同输入、同代际幂等；旧代际结果不应用，游标不提前推进 |
| V17 | 相关同义/跨语言与无关问题 | 量化召回和误召回；引用与最终答案正确，不靠增加 chunk 冒充改善 |
| V18 | held 第三人/未确认推断 | 不被 Relationships、reflection 或 entry 路径提升成事实 |
| V19 | 普通 end/flush、子 Agent | 不直接触发 LLM；受限 child/非用户派生消息不冒充 L0 用户证据 |
| V20 | DSH 重连、新回合与话题切换 | alignment/compact/index 实际消费，重复 step 去重，源变化刷新 |

## 4. 档位和判定

文档审计：链接、证据引用、版本/依赖/边界一致；不运行 Rust/TS 测试。

实施时先完成 Rust/TS 必要检查和确定性契约测试，再在临时库跑 API/CLI，随后官方 DSH 固定响应验证注入/工具顺序，最后有限真实模型对话观察。每档分别记录通过/失败/未验证；不能用固定响应宣称真实质量，也不能只验证 memoryd curl。

合成集关键契约（越域、逐字来源、失效注入、遗忘复活、虚报保存）零违反；V13/V14 必须包含交接 25 的 FP/FN 锚定场景。泛化质量报告样本量、相关/不相关标注、precision/recall、答案利用率和新增误召回，不预设“7 active = Muse 级质量”。同模型对照冻结模型/语料/参数，必要时区分候选数变化，不能强行当成逐候选配对。

只有 V2-H1 完成宿主实际行为，才能说对应记忆能力闭环。完整人物覆盖受准入政策限制、Muse 私有排序未知等仍须保留差异声明。云端部署另按根 AGENTS 的 WSL 实际部署测试规则执行；本计划不授权触碰用户原库或生产环境。
