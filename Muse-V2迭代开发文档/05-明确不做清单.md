# 05 · 范围取舍与尚未确定的 Muse 内部机制

> “暂缓”是当前开发取舍，不能改写成 Muse 没有此能力。quiet pass、dated reflection、索引延迟加载与可读投影均已进入 V2 核心。

## 1. 当前暂缓

| 项目 | 证据支持什么 | 取舍及边界 |
|---|---|---|
| Ideas tab / Idea curation | 官方文档定义每日卡片及三维评价 | 暂缓独立产品面；来源理解仍由 V2 upkeep/Dream 提供 |
| Goals tab / Studying | 官方文档定义夜间简报、进展提示及隐式目标建议 | 暂缓研究简报；若以后启用，隐式目标是建议，不成为用户已承诺目标 |
| Skill review | 官方文档定义技能生成、审计和无益变更退役 | 暂缓自动技能写入；不影响本次记忆复盘的 action/repair |
| shopping 专用面 | 观察到 shopping/PROFILE.md | 暂缓专用购物流程；已有通用偏好可以进入 world/opinions/主题投影 |
| 可写文件与 DB 双向同步 | 文件编辑纪律可观察，具体同步协议不可见 | 当前提供只读投影和版本化编辑接口；双向导入需另行设计证据、冲突和删除协议 |
| 仿 Muse 固定向量维度/权重 | Schema 有 vector(384)，权重未知 | 保留现有模型配置和已实现语义支路；不能只因 384 仿得像就改模型 |
| salience 排序算法 | Schema 有 salience，算法未知 | 暂不增加未校准的评分机制；保留未知项，不再称已证伪 |
| Muse memory/index/ 用途 | 空目录 | 无行为证据，暂不仿一个无功能目录 |

以上不是新增对外授权或部署决定；仅限定本轮文档与后续施工范围。

## 2. 明确纳入核心

Quiet-moment 是文档定义的 bounded internalization，没有 Tab 输出。原稿“产品层无场景、价值密度低”的理由无证据，撤销。纳入有信号、有上限、不重复消化的后台任务，普通 turn/end/flush 仍不直接触发 LLM。

Dreaming 的关键是得失、修复与行动综合，不是散文修辞。M3 指标和固定指导句不覆盖它；V2 输出有来源的 dated reflection 与具体行动 synthesis，可同时生成便于人读的复盘投影。无需额外一轮 LLM 只润色散文。

MEMORY/bank/people/dreams 文件的可读性与定位具有已观察价值。V2 提供单源投影、stable refs、精读与 explain，不用“可读性需求低”作为省略理由。

## 3. 需要产品决定但不阻塞当前文档的事项

- 自动人物事实准入：现行 THIRD_PARTY 门限制完整 Muse 人物事实覆盖。先做合法来源关系投影；扩大自动准入须先明确政策并新建版本。
- side 域继承与分享：本文选择 side 默认继承主域、跨 side 必须授权；这是 V2 策略，不是 Muse 已证明权限矩阵。
- 可写文件导入：当前采用 DB 唯一源，不作为已获批准的双真相源方案。后续若选择导入，再定义版本冲突与来源规则。

这些缺口要在验收结果中列出，不把暂缓当作全等复刻。没有 Muse 可用对照端点时，只报告本地契约与离线行为结果。
