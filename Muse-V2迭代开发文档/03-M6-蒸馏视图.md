# 03 · V2-D1：蒸馏、精炼常驻与可读投影

> 依据：[报告 04](../Muse记忆系统分析报告/04-源证据-文件层实物.md)、[Muse文档 01 §1.2—1.4](../Muse文档/01-存储层.md)。
> 四文件与部分内容是观测；“全部只是重排、可以精确按 kind 分桶”未得到完整样本支持。

## 1. 保留三个不同产物

| 产物 | Muse 观察 | V2 目标 |
|---|---|---|
| 精炼常驻 | MEMORY.md，事实/偏好/承诺，小而有用 | 从有效记忆生成有预算、可重建的 compact_memory；每轮 V2 bundle 可消费 |
| 日期轨迹 | dated notes，获知方式、quote、消息引用和修正记录 | 从受控事件与修订生成按日可读轨迹，非原始聊天全文备份 |
| bank 四分面 | experience/opinions/reflections/world；runtime 维护、Agent 只读 | 逐条带来源的分面投影，按需读取，不把全部内容常驻注入 |

Resident 当前是 pin/视图机制，不自动等于完整的 MEMORY.md 精炼层。V2 的 compact_memory 与用户手动 pin 的 Resident 区分，去重后一起进入明确预算；来源失效和用户修正优先于生成器旧理解。USER.md 的用户本人概况可从受控 profile/compact 读取，不能把用户放到 people 中，也不能由后台改 Soul。

## 2. 四分面规则

| 分面 | 包含什么 | 不可采用的原稿简化 |
|---|---|---|
| experience | 有时间与主体的经历、结果、重要变化 | 不仅等于 kind=episode |
| opinions | 稳定偏好、判断、价值取向，保留主体和条件 | 不仅等于 preference；instruction 也可能表达偏好 |
| reflections | 有证据的得失、纠正原因、行为调整及版本关联 | 有 supersedes 链并不自动等于反思 |
| world | 用户处境、关系和持久事实，保留不确定性与有效期 | valid_until=NULL 不证明长期有效 |

同一条可以出现在多个分面，条目须有 facet、body、source_refs、observed_or_inferred、generator_version、domain、source_fingerprint、version、generated_at。事实可以确定性摘录；多源概括由 upkeep/Dream 的版本化生成器提议，Rust 校验来源和状态。

反思中模型判断标为派生解释，不得变成 L1 用户事实、事实级置信度或 Soul。稳定承诺仍需要用户证据，不能把任务清单直接抄进常驻记忆。无长期变化时不更新 compact；无反思来源时该分面可为空。

## 3. 物化与来源

采用版本化 derived_documents/items/sources（具体表名施工时确定）或扩展已有页面机制。四个 SQL kind 过滤只能作为基线对照，不算 V2 蒸馏交付。

每条 source_refs 至少包括 memory_id/version/claim_sha256，必要时带 evidence/span 或受控修订引用。历史记录与当前可注入数据分别判权限和有效性；引用旧值作为纠正背景时显式标记“旧值已失效”。正常 recall 不因分面内容含旧值而恢复旧事实。

发布前复核冻结输入指纹；派生正文和引用同事务提交。来源变化即 stale，读路径即时屏蔽，不等下一小时重建。多来源混合段落失去其中一条依据时，先隐藏受影响段再重算；其他有效段可继续可见。

## 4. DB 与 Markdown 的边界

沿用现有 Rust/DB 唯一裁决源，提供只读 Markdown 投影：compact MEMORY、每日 notes、四个 bank 分面、people/groups 索引和页、dated dreams/alignment。目录语义尽量与观察一致；无需仿 Muse 私有绝对路径。

投影包含稳定 URI、版本、生成时刻、来源定位和当前状态。文件行号仅是该导出版本的位置，不作为永久主键；文件重排后 stable ref 仍可解释。输出由 renderer 从同一数据库快照生成，原子替换并保留 manifest；Agent 只能读，不能覆盖 runtime 产物。

多用户/side 域导出到分别授权的路径，不得落到全用户可见的混合目录。purge 清理对应投影正文和历史缓存，并验证重导出不会复活；失败明确记录 incomplete。

可写导入/双向同步暂缓，原因是当前唯一裁决源和版本一致性约束，不是“个人用户可读性低”。需要人类编辑时走带 expected_version 的用户编辑接口，再重建投影。以后新增导入必须定义冲突、删除、证据和原子同步协议。

## 5. 验收

同语料对照纯 kind 分桶与分面结果：跨 kind 正确归面、有时间的事实进 experience、多命题不合并编造、条件与引用不丢、无内容允许空、稳定记忆足够精简。常驻和检索重复条目只注入一次。

更正后 compact/world 中旧值消失、日期轨迹能解释更正；退役/过期/forget 后派生注入立即失效；purge 后全文、索引、导出和旧缓存不留副本。相同冻结输入重建产物可追踪且不重复版本，无关回合不会注入整部 bank。
